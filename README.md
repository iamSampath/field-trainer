# Field Trainer

A flip-through cricket fielding manual. It teaches the 22 standard fielding positions with animated fielders, then tests you with a practice quiz.

## Chapters

1. **Reading the ground**: off side, leg side, inner ring, deep, straight, square, fine, silly
2. **Close catchers**: keeper, slips, gully, leg slip, silly point, short leg
3. **The ring**: point, cover, extra cover, mid-off, mid-on, midwicket, square leg
4. **The boundary**: third man, fine leg, deep point, deep cover, long-off, long-on, deep midwicket, deep square leg
5. **Left-handers**: watch the whole field mirror
6. **Practice nets**: Name it, Find it and Random field quizzes, with score and streak

## Use it

Open `index.html` in any browser. It's a single file with no build step. To host it, turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch, root folder).

Turn pages with the on-screen buttons, the ← → keys, or a swipe on a phone.

> Fielding restrictions (how many fielders can stand outside the ring, and when) differ between leagues. Check your league's playing conditions.
